# Kho Tiện Ích Mở Rộng vBook - LuanLuftwaffe\n\nKho lưu trữ tiện ích mở rộng (extensions) dành cho ứng dụng đọc truyện **vBook** trên Android/PC.\n\n## 🚀 Hướng Dẫn Cài Đặt Vào vBook\n\n1. Mở ứng dụng **vBook** trên điện thoại.\n2. Vào menu **︙ (Menu góc phải)** → **Phần mở rộng** → chọn tab **Kho lưu trữ**.\n3. Bấm **Thêm kho lưu trữ** (nút dấu +).\n4. Dán đường link sau vào rồi bấm **Lưu**:\n   `	ext\n   https://raw.githubusercontent.com/LuanLuftwaffe/luanluftwaffe-ext-vbook/main/sources.json\n   `\n5. Bấm vào kho **LuanLuftwaffe** vừa thêm và nhấn **Cài đặt** tiện ích **Multi-API Translate**.\n\n---\n\n## 📦 Danh Sách Tiện Ích Trong Kho\n\n### 1. Multi-API Translate (v1)\n* **Thể loại:** Tiện ích Dịch Thuật (	ranslate)\n* **Mô tả:** Dịch, viết lại convert đa nguồn API: Google Gemini, DeepSeek, Claude, OpenAI & bên thứ 3. Tự xoay key, Cache 0ms, Anti-Stop chống dừng tải\n* **Tính năng nổi bật:**\n  * **Đa chuẩn API:** Hỗ trợ trực tiếp Google Gemini Native REST, Anthropic Claude Native, OpenAI Compatible (DeepSeek, Groq, OpenRouter...).\n  * **Google Gemini thế hệ mới:** Tích hợp sẵn Gemini 3.1 Pro Preview, 3.5 Flash-Lite, 3.6 Flash, 3.8 Flash, 4 Argon (tự động bypass bộ lọc an toàn BLOCK_NONE).\n  * **DeepSeek & Model suy luận:** Hỗ trợ DeepSeek V3, DeepSeek R1 (tự động khử 	emperature chống lỗi HTTP 400).\n  * **Anthropic Claude:** Dùng trực tiếp API Key Claude (sk-ant-...) qua Messages API.\n  * **Mua API bên thứ 3 & Tự host:** Hỗ trợ tùy chỉnh custom_model và custom_endpoint khi mua API qua đại lý (OpenRouter, SiliconFlow, Together AI...) hoặc chạy Ollama mạng LAN.\n  * **Tối ưu tốc độ:** Bộ nhớ đệm Cache chương 0ms, xoay vòng nhiều key tự động và Anti-Stop chống dừng tiến trình khi treo máy tải hàng loạt.\n
